# Ball Run 2048

참고 영상의 숫자 공 러너를 바탕으로 만든 Three.js + Rapier 3D 게임입니다.

[게임 플레이](https://ryanjun1002.github.io/ball-run-2048/)

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 형식 검사, 테스트, 빌드를 실행한 뒤 GitHub Pages에 배포합니다. 저장소의 Settings → Pages에서 배포 소스는 GitHub Actions를 사용합니다. 빌드 경로는 상대 경로로 설정해 저장소 하위 주소에서도 실행됩니다.

## 실행

```powershell
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 여세요. `npm run build`로 배포 파일을 생성하고 `npm run preview`로 확인할 수 있습니다.

## 게임 모드

- **일반 모드**: 아쿠아 산책, 민트 점프, 선셋 슬라이드, 아이스 드리프트, 라벤더 브리지, 스타라이트 런의 6개 스테이지. 목표 숫자로 완주하면 별을 받고 다음 스테이지가 열립니다.
- **무한 모드**: 끝없이 생성되는 88m 단위 코스. 주행 거리에 따라 속도가 높아지고, 최고 거리와 최고 숫자를 별도로 기록합니다. 큰 숫자는 K/M/B/T, 이후에는 `2^지수`로 표시해 숫자 오버플로를 피합니다.

## 조작과 규칙

- 마우스·터치를 좌우로 드래그하거나 방향키, A/D로 이동합니다.
- 공은 자동으로 앞으로 구르며 같은 숫자와 합쳐지면 두 배로 커집니다.
- 무지개 `×2` 공은 현재 숫자를 항상 두 배로 만듭니다. 숫자가 다른 공은 크기에 관계없이 서로 튕기며, 숫자와 점수는 변하지 않습니다.
- 트랙 가장자리는 넘을 수 있는 낮은 턱입니다. 너무 멀리 움직이거나 부딪혀 밀려나면 바다로 떨어집니다.
- 빨간 스파이크, 기둥, 움직이는 범퍼에 닿으면 숫자가 절반이 됩니다. 숫자 2에서 다시 맞거나 물에 빠지면 종료됩니다.
- 노란 발판에서는 자동으로 점프합니다. 난간 없는 다리는 가운데로, 얼음 위에서는 미리 방향을 바꿔 주세요.
- Space로 시작·일시 정지, Escape로 일시 정지·복귀할 수 있습니다. 탭을 벗어나면 자동 정지합니다.
- 설정에서 효과음·음량, 눈 장식, 차분한 효과를 바꿀 수 있습니다. 진행 상황과 설정은 이 브라우저에 저장됩니다.

## 실제 물리 계산

Rapier의 동적 강체와 구형 충돌체를 사용합니다. 중력, 마찰, 반발력, 관성, 질량, 지형·공·장애물 충돌을 120Hz 고정 간격으로 계산합니다. 회전은 물리엔진의 쿼터니언을 그대로 화면에 반영하며, 공 표면의 띠와 작은 점으로 회전을 확인할 수 있습니다. 숫자는 공 표면 한쪽에만 붙어 물리 회전과 함께 구릅니다.

공의 크기와 질량은 숫자에 따라 달라집니다. 전진과 조향에는 플레이 편의를 위한 보조 힘을 사용하므로 과학 실험용 시뮬레이터와는 조작감이 다릅니다. 크기는 통로를 통과할 수 있도록 제한하고 숫자는 계속 증가합니다.

무한 모드는 앞 코스를 생성하고 지난 코스의 물리·그래픽 객체를 제거합니다. 256m마다 좌표 원점을 옮겨 장시간 진행 시 부동소수점 오차를 줄입니다. 숫자 텍스처도 제한된 캐시로 관리합니다.

## 소리

브라우저에서 직접 합성한 굴러가는 소리, 숫자 합치기, 튕김, 충돌, 점프, 착지, 물에 빠짐, 클리어 효과음이 들어 있습니다. 첫 플레이 버튼을 누르면 오디오를 활성화하며, 외부 음원이나 유료 API가 필요하지 않습니다.

## 코드 구조

- `src/course.ts`: 스테이지, 지형, 코스 생성, 숫자 표시
- `src/physics.ts`: Rapier 강체·충돌체, 힘, 점프, 좌표 원점 이동
- `src/simulation.ts`: 합치기·피해·승패·무한 코스 진행
- `src/render.ts`: Three.js 화면, 공 회전·크기, 테마, 물결, 효과
- `src/main.ts`: 입력, 메뉴, 게임 루프
- `src/audio.ts`: Web Audio 효과음과 주행 소리
- `src/progress.ts`: 저장 데이터 검증과 스테이지 해금

## 검증

- `npm test`: 실제 물리엔진으로 6개 스테이지 완주, 30/60fps 결과, 다른 숫자 반발, 트랙 양옆 낙하, 일시 정지, 저장 데이터 검증, 무한 모드 2,500m와 객체 수 제한을 검사합니다.
- `npm run build`: 엄격한 TypeScript 검사와 배포 빌드입니다.
- `npm run format:check`: 코드 형식을 검사합니다.

Three.js와 Rapier를 별도 캐시 파일로 분리했습니다. Rapier 호환 패키지는 WebAssembly를 내장해 약 4.3MB(전송 압축 시 약 1.6MB)이며, 첫 로딩에 초기화 화면을 표시합니다. 이 크기를 고려해 청크 경고 기준을 5MB로 설정했습니다. WebGL과 WebAssembly 지원이 필요합니다. Google Fonts를 불러오지 못하면 시스템 글꼴을 사용합니다.
